Make your own and share it
  1. Make one .html file with everything inside it (styles and scripts too). Copy the dice roller to start.
  2. Test it here with Add an .html file.
  3. To share it with everyone, open a pull request on GitHub that adds your file to toolbox/community/ and a line to toolbox/community/apps.json. Once it’s accepted, it shows up for every ToolBox user.
