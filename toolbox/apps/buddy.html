Paste your notes and get quizzed on them. With a Claude API key, Claude writes real questions (multiple choice and short answer) and marks your answers with feedback. Without a key, it still works offline using fill-in-the-blank questions.

🔑 Claude API key

Get a key at console.anthropic.com. It's saved only in this app on this device and is sent only to Anthropic's API. Each quiz costs a few cents.
