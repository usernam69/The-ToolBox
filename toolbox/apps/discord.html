Pick what your bot can do and download a ready-made project. It's a discord.js bot with slash commands. Once you've created the bot on Discord's developer site, it runs on your own computer with Node.js.

Commands

Your own reply commands

One per line, like rules: Be kind, no spam, have fun!. Each one becomes /rules.



How to run it
    

  1. Install Node.js (the LTS version).
    2. 

  2. Go to the Discord Developer Portal, click New Application, then open Bot → Reset Token and copy the token.
    3. 

  3. Unzip the project, rename .env.example to .env, and paste your token and the application ID (from General Information). Never share the token or post it online.
    4. 

  4. Invite the bot: OAuth2 → URL Generator, tick bot and applications.commands, open the link, and pick your server.
    5. 

  5. In the project folder run npm install, then npm start. Type / in your server to see the commands.
